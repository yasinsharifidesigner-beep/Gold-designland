# گولد دیزاین لند

صفحهٔ اصلی سایت از `/` سرو می‌شود. پنل کاربری روی همین سرور است و صفحهٔ اصلی را عوض نمی‌کند.

## اجرا

```
npm install
npm start
```

سپس:

- صفحهٔ اصلی: http://127.0.0.1:3000/
- ورود پنل: http://127.0.0.1:3000/auth/login

## حساب نمونه

- یاسین شریفی، شماره `09123456789`، رمز `12345678` — میز کار پر و دادهٔ تصویرها
- سارا نمونه، شماره `09120000000`، رمز `12345678` — حالت‌های خالی
- کد پیامکی آزمایشی همیشه `42971` است و پیامکی فرستاده نمی‌شود

## فرض‌ها

داده در پایگاه ذخیره می‌شود. اگر `DATABASE_URL` باشد PostgreSQL است، وگرنه فایل SQLite در `DB_PATH` (پیش‌فرض `./data/gdl.sqlite`). پیامک واقعی و درگاه بانکی هنوز نیستند. پرداخت آزمایشی مستقیم به صفحهٔ «فعال شد» می‌رود؛ اگر متغیر `PAYMENT_MOCK_RESULT=fail` باشد، به خلاصهٔ خرید برمی‌گردد.

ورود مدیر روی `/admin` است و با `ADMIN_PHONE` و `ADMIN_PASSWORD` روشن می‌شود. حساب‌های نمونه فقط وقتی ساخته می‌شوند که `NODE_ENV` برابر `production` نباشد.

## مدیر

- نشانی: http://127.0.0.1:3000/admin

منوی موبایل یک دکمهٔ همان آیکن منو است که همان ۹ آیتم را نشان می‌دهد، بدون متن تازه.

کد تخفیف آزمایشی `GDL20` است و ۲۰ درصد کم می‌کند.

جلسهٔ ماتریکس در سند عنوان جدا نداشت؛ پنج جلسه با عنوان «جلسهٔ ۱» تا «جلسهٔ ۵» گذاشته شد تا ۲۰ درصد پیشرفت دیده شود.

پروژهٔ «انگشتر اسلیمی» در فهرست پروژه‌ها روی مرحلهٔ ساخت تصویر است و در صفحهٔ جزئیات روی اصلاح و انتخاب طرح، چون خود سند گفته این دو تصویر با هم فرق دارند.

ویدیوی دوره فایل واقعی ندارد؛ پخش‌کننده و زمان‌های فارسی دیده می‌شوند و با زدن پخش، جلسه دیده‌شده ثبت می‌شود.

عکس طرح‌ها و جلد دوره‌ها جای‌نگهدار خطی هستند، چون فایل‌های JPG طرح روی این سیستم نبود.
